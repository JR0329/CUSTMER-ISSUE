# 客訴快速填單 - App版（PWA，可離線安裝）

這個版本可以像真正的App一樣「安裝」到手機主畫面，安裝完成後**完全不需要網路**就能使用，
不管手機品牌、公司發的還是自己的都適用。

## 這5個檔案要放在同一層資料夾，缺一不可

- `index.html`（主程式）
- `manifest.json`（App安裝設定）
- `sw.js`（離線快取機制，讓App離線也能打開）
- `icon-192.png`、`icon-512.png`（App圖示）

## 部署步驟（您這邊只需要做一次）

因為手機需要透過網路「安裝」這個App一次，之後才能完全離線使用，
所以需要先把這5個檔案放到一個網址上：

1. 到 github.com 註冊免費帳號（如果還沒有）
2. 建立一個新的 repository，設為 **Public**（公開，因為裡面完全沒有客戶資料，
   只是空白表單程式本身，公開沒有資料外洩疑慮）
3. 把這5個檔案全部上傳進去（保持檔名完全一致，不要改）
4. 進入該 repository 的 **Settings → Pages**
5. Source 選擇 `main` 分支、根目錄，按 Save
6. 等1-2分鐘，畫面會顯示一個網址，格式類似：
   `https://您的帳號.github.io/repository名稱/`

這個網址設定好之後就不用再管了，除非之後要更新程式內容。

## 工程師這邊要做的事（每個人的手機各自做一次）

**iPhone (Safari)：**
1. 用 Safari 打開上面那個網址（不要用LINE/email內建瀏覽器打開）
2. 點畫面下方中間的「分享」圖示（方框+箭頭）
3. 往下滑選單，點「加入主畫面」(Add to Home Screen)
4. 點右上角「加入」

**Android (Chrome)：**
1. 用 Chrome 打開上面那個網址
2. 點右上角「⋮」選單
3. 點「新增至主畫面」或「安裝應用程式」
4. 確認新增

完成後，手機桌面會出現一個「客訴填單」的App圖示，點開會是全螢幕的App畫面
（不會看到瀏覽器網址列），**之後即使沒有網路訊號、飛航模式，也能正常打開填寫**。

## 這個機制為什麼能離線運作

Service Worker (`sw.js`) 會在第一次連線安裝時，把整個App的內容(HTML/圖示等)
下載並存進手機本機的快取空間，之後每次打開App，會優先讀本機快取的版本，
不會再去連網路要求資料，所以斷網也能正常使用。

## 使用方式(跟之前的離線HTML版本完全一樣)

填寫表單，按送出，會下載一個CSV小檔案，傳給資料庫負責人整理即可，
細節請參考 `README_complaint_entry.md`。

## 之後如果要更新App內容

改完 `index.html` 後，重新上傳到同一個github repository覆蓋舊檔案即可，
但**手機端已經安裝的App不會自動更新**(因為它離線使用本機快取)，
使用者需要在有網路時重新打開一次App，讓Service Worker偵測到新版本並更新快取
(這是PWA的正常機制，第一次打開可能還是顯示舊版，第二次才會是新版)。
